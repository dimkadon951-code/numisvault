# NumisVault

Персональный кроссплатформенный каталог коллекции монет: Windows + Android,
одна кодовая база на Flutter, общая облачная коллекция и офлайн-режим.

## Что внутри

**Стиль.** «Тёмная роскошь»: махагон с текстурой волокон, бархат (зелёный и
бордовый) с ворсом, латунные окантовки, винты, гравированные подписи.
Текстуры рисуются процедурно на `CustomPainter` — без тяжёлых картинок,
в 60 к/с и с чёткостью на любом DPI.

**3D-монета** (`lib/widgets/coin_3d.dart`) — центральный элемент:
* перспективное вращение вокруг вертикальной оси (`Matrix4 ..setEntry(3,2,…)..rotateY`);
* толщина и гурт из 10 слоёв-дисков, разнесённых по Z;
* инерция после свайпа, «магнит» к аверсу/реверсу, тап = переворот на 180°,
  колесо мыши для доводки угла;
* металлический блик: две движущиеся диагональные полосы в `BlendMode.plus`,
  цвет берётся из металла монеты (золото/серебро/медь/биметалл…);
* видимая сторона всегда удерживается в пределах ±90°, поэтому монета
  не «выворачивается» и не зеркалит изображение.

**Фото.** Загруженное фото проходит через экран ручной подгонки
(`lib/screens/crop_screen.dart`): пинч/колесо для масштаба, перетаскивание для
центровки, затем снимок области через `RepaintBoundary.toImage` обрезается
ровно по кругу с прозрачным фоном. Качество автоматически понижается, пока
PNG не уложится в лимит, — картинка остаётся круглой при вращении.

**Анимации.** Появление карточек «из бархатного ящика» (подъём + наклон по X),
`AnimatedSwitcher`-переход между наборами фильтров, зум карточки под курсором,
лупа `RawMagnifier` над монетой на ПК.

| Файл | Экран |

| `lib/screens/home_screen.dart` | Витрина: поиск, чипы по металлу, фильтры по стране/году/сохранности, сортировка, адаптивная сетка 2–5 колонок |

| `lib/screens/login_screen.dart` | Вход в облако (или локальный режим) |

## Данные и синхронизация

`CoinStore` (`lib/data/coin_store.dart`) — офлайн-first:

1. Любое изменение сразу ложится в дисковый кэш (`coins.json`, `queue.json`,
   PNG в `images/`) — приложение читается без интернета.
2. Изменение ставится в очередь и уходит в Supabase.
3. Нет сети — операция ждёт, в шапке показывается «N В ОЧЕРЕДИ», повтор
   каждые 12 секунд и по кнопке статуса.
4. Realtime-поток (`coins` → `updated_at`) перезаписывает локальный список,
   поверх него накладываются ещё не отправленные операции — правки не теряются.

Схема БД: `supabase/schema.sql` (таблицы `coins`, `coin_images`, RLS «только
свои данные», публикация Realtime).

Облако настраивается в одном месте — `lib/config.dart` (или через
`--dart-define`). Без ключей приложение работает локально.

## Требования

Flutter 3.27+ (Dart 3.6+). Для `.exe` — Visual Studio 2022 с C++,
для `.apk` — Android SDK 34/35 и JDK 17.

## Быстрый старт

```powershell
cd NumisVault
flutter create --project-name numisvault --org com.numisvault --platforms=windows,android .
flutter pub get
flutter run -d windows --dart-define=SUPABASE_URL=https://xxx.supabase.co --dart-define=SUPABASE_ANON_KEY=eyJ...
```

Полная инструкция по установке, сборке `.exe`/`.apk`, подписи и типовым
ошибкам — в [INSTALL.md](INSTALL.md).
